# Temperature Monitoring and Controlling IoT Device

- <strong>Task</strong>: To do Component selection, Electrical circuit designing, PCB designing and Microcontroller programming.
- <strong>Type</strong>: Freelance project - India
- <strong>Discription</strong>:
<ul><ul>
<li>It is an Industrial Temperature Monitoring and Controlling IoT device. The device monitored and maintained temperature of a boiler. </li>
<li>Researched, designed, and implemented a full-stack embedded system using ESP32 S3 microcontroller.</li>
<li>Developed a 4 Layer Industrial Grade PCB.</li>
<li>Developed a small programmable interface using 4 buttons for setting the temperature threshold.</li>
<li>Integrated a industrial 4 digit seven segment display of 4 inches.</li>
<li>Integrated USBC interface for flashing the ESP32.</li>
<li>Developed a robut C++ firmware.</li>
</ul></ul>
