# Helmet Wear Detection Device

- <strong>Task</strong>: To do Component selection, Electrical circuit designing, PCB designing and Microcontroller programming.
- <strong>Type</strong>: Freelance project - Canada
- <strong>Discription</strong>:
<ul><ul>
<li>Researched, designed, and developed a complete embedded system for Helmet Wear Detection device. This device can detect if the helmet is being worn or not.</li>
<li>Developed ESP32-C3 based Embedded system from ground up (Hardware and Firmware)</li>
<li>Developed a customized compact sized and light PCB design (Rectangular, 36mm X 39mm).</li>
<li>Integrated sensors ToF.</li>
<li>Developed drivers for sensor to work efficiently on board by carefully analysing the datasheets.</li>
<li>Developed a full power management system: Battery charging/handling circuit with protection standards, Voltage regulatory circuit, etc.</li>
<li>Developed a complete Software integration with WiFi pipeline and Web Dashboard.</li>
