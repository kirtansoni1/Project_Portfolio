# Predictive Maintenance Device

- <strong>Task</strong>: To do Component selection, Electrical circuit designing, PCB designing and Microcontroller programming.
- <strong>Type</strong>: Freelance project - Germany
- <strong>Discription</strong>:
<ul><ul>
<li>The device is attached to a hydraulic machine to monitor key performance parameters using multiple industrial-grade sensors. It collects real-time data and classifies machine faults using edge processing.</li>
<li>Researched, designed, and implemented a full-stack embedded system for a predictive maintenance solution tailored to hydraulic systems.</li>
<li>Selected and integrated 14 sensors including pressure, temperature, vibration, flow, and power sensors with proper interfacing and calibration.</li>
<li>Engineered a robust data acquisition pipeline capable of sampling up to 100 Hz per sensor, optimized for noise resilience and low-latency transmission.</li>
<li>Developed highly efficient firmware in C++ using FreeRTOS for task scheduling, DMA-based ADC reads, and USB CDC communication.</li>
<li>Designed custom PCB and power management system based on the ESP32-S3-WROOM-1 microcontroller, enabling USB-C ESD protection and onboard 3.3V regulation.</li>
<li>Ensured modular and scalable system architecture ready for cloud offloading and machine learning model integration on the edge.</li>
</ul></ul>
